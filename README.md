# 医院门诊医生排班与号源平台

## 项目简介
一个面向小型连锁门诊诊所的医生排班与号源管理平台。
目前处于基础建设阶段（D10），已完成底层3张数据库表设计、医生/科室的基础CRUD、分页及条件查询功能。后续将陆续加入排班、鉴权、缓存等功能。

## 业务痛点（当前已完成的部分）
1. 医生停诊不能物理删除——医疗合规要求保留诊疗记录（使用 status 字段标记：0在岗/1停诊/2离职，删除改更新，查询过滤 status=0）
2. 执业证号不能重复——重复会引发重大医疗事故（唯一索引 uk_license + 后续业务层查重）
3. 排班冲突——同一医生同时段不能重复排班（schedule 表联合唯一索引物理拦截）

## 技术栈（当前进度）
后端：SpringBoot + MyBatis + MySQL + Maven
开发工具：IDEA + 通义灵码（IDEA插件）+ Git

## 功能清单（当前进度）
- 科室管理：建表（clinic_dept），基础增删改查
- 医生管理：建表（doctor），增删改查 + 分页查询（Limit） + 动态条件查询（按科室、职称）
- 停诊软删除（逻辑删除）：利用 status 字段做标记，查询时强制过滤 status=0
- 排班表基础设计：建表（schedule），核心唯一索引 (doctor_id, shift_date, shift_type) 防重复
- 详细设计见项目内数据库文件
